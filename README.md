# UX Content Auditor

A UX writing and UI content auditing skill for AI coding agents.

Automatically reviews existing and new interfaces to identify and remove unnecessary, redundant, misleading, or poorly written content.

### Features
- Audits existing and newly created interfaces.
- Removes unnecessary text and redundant descriptions.
- Prevents technical requirements from leaking into UI copy.
- Improves clarity, consistency, and natural language.
- Reviews buttons, forms, labels, notifications, and messages.
- Preserves accessibility and essential user information.

### Installation

Place `SKILL.md` in:

```text
.agents/skills/ux-content-auditor/SKILL.md
```

### Core principle

**Every piece of content must have a purpose. If it provides no genuine value to the user, remove it.**

Less unnecessary content. Better interfaces.
